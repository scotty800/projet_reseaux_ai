# 🏠 Smart Home Security System

Système de sécurité domestique simulé avec détection d’intrusions via IA.  
Projet complet combinant **Python, Ansible, Flask** et **Machine Learning**.

---

## 🚀 Fonctionnalités

- Capteurs simulés : porte, fenêtre, mouvement  
- Collecte automatique des données CSV  
- Détection d’intrusions simple et via Isolation Forest  
- Déploiement automatique sur plusieurs appareils via Ansible  
- Dashboard Web Flask pour visualiser mesures et alertes
