# projet_reseaux_ai# 🔒 Network Analyzer & Security Auditor

Outil d’analyse réseau et de sécurité automatisé, intégrant de l’IA pour détecter des configurations à risque.  
Projet complet combinant **Python, Ansible, Flask** et **Machine Learning**.

---

## 🚀 Fonctionnalités

- 🕵️‍♂️ Scan d’un sous-réseau local
- 🔗 Collecte de configuration SSH
- ⚡ Audit des ports ouverts
- 🔒 Détection de risques (ports critiques)
- 🤖 Détection d’anomalies avec IA
- ⚙️ Déploiement automatique via Ansible
- 📊 Dashboard Web Flask
